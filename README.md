# 学校給食 調理作業工程表メーカー

学校給食の調理作業工程表を、ブラウザ上で作成・編集・印刷できるツールです。
手書きで工程表を作成する負担を減らすために試作しました。

## 使い方

GitHub Pages で公開されているページを開くだけで使えます（インストール不要）。
手元のPCで使いたい場合は、`index.html` をダウンロードしてブラウザで開いてください。
単一ファイルで動作し、インターネット接続は不要です。

- 献立プリセット（実例工程表）を選んで、献立・担当者・時間を編集
- 施設プロファイル設定で、学校名・提供区分（親子方式／単独校／給食センター）・検印欄・調理員名簿を自施設向けに変更可能
- 汚染区域（ピンク枠）・外作業（青枠）のマーカー、釜・機器スタンプと重複チェック
- 衛生・工程チェック集計、印刷／PDF出力、JSON形式での保存・読込
- 入力内容はお使いのブラウザ内（localStorage）にのみ保存され、外部に送信されることはありません

## 収録データについて

収録されている学校名・氏名・献立は、すべてサンプルの架空データです。
実在の学校名・個人名は含まれていません。

## 技術メモ

- 単一HTMLファイル（CSS／JavaScript内蔵、外部リソースへの依存なし）
- スタイルは Tailwind CSS v3.4.17 を静的に生成して埋め込み
